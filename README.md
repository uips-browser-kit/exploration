## What belongs here

- research spikes (even dead ends)
- notes on third-party browser automation approaches
- feasibility findings that informed or ruled out scope decisions
- ideas not ready for library

## What does not belong here

- code intended to ship (use library)
- safe experiments you expect to revisit (use playground)
